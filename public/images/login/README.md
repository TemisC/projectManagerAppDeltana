# Login background image

Drop a file named **`hero.jpg`** in this folder (`public/images/login/hero.jpg`)
and the login screen will pick it up automatically as the background of the
left branding panel — no code change needed.

- Recommended size: at least 1920x1080, landscape orientation.
- If the file is missing, the panel falls back to a plain dark gradient (no broken-image icon).
- To swap the image later, just replace this same filename.
